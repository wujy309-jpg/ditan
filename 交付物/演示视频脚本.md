## 二、为什么重做

上一版是「截图 + 大段文字」的合成片，看起来像在讲 PPT，不像在演示作品。
这一版把**模拟器窗口直接录下来**：

- 所有滚动、点击、输入都是真实发生的，能看到页面在动、数据在变；
- 录屏原生 760×1284，合成到 16:9 后仍是清晰可读的；
- 左侧只保留步骤标注与「实时录屏」提示，不再放设计说明；
- 旁白只讲「点了什么、发生了什么」，不讲设计理念。

## 三、录制与合成

```bash
# 抓取模拟器窗口（macOS AVFoundation，区域为窗口内屏幕）
ffmpeg -f avfoundation -framerate 30 -capture_cursor 0 -i "2" \
  -vf "crop=760:1285:822:78" -c:v libx264 -preset ultrafast -crf 18 out.mp4

# 操作通过 hdc 注入（uinput -T / -K），分段录制后合成
python3 tools/docs/record_demo.py
python3 tools/docs/make_realdemo.py
```

说明：录屏过程中新增了一条 6 公里步行记录，因此视频里后半段的累计减排与积分
会比文档/PPT 截图（20.58 kg / 2,058 分）略有增长，这是真实操作的结果。
