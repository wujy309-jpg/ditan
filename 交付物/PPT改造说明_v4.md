## 一、这版的视觉基调

| | **墨迹档案** |
|---|---|
| 底子 | 米纸 `#F4EFE3` + 墨 `#1E211C` + 朱砂 `#B23A2A` + 苔绿 `#6F8F7C` |

**为什么是这个基调**：技术赛的评委先看"信不信"，再看"美不美"。所以整份用纸墨压住花哨，把强调色只留给"判断句"和"关键数字"——朱砂一出现，就是这一页要你记住的那句话。

## 二、这一版改了什么（相对原 23 页）

1. **结构从"功能清单"改成"四幕论证"**：问题（3 个坎 → 三类做法）→ 方案（五环 → 三处取舍 → 赛题对照）→ 演示（五处可触发 + 鸿蒙延伸）→ 证据（同步 / AI / 碳普惠 / 凭证 / 架构 / 因子 / 测试 / 界面）→ 边界与收束。新增 4 个章节页，删掉原"答辩重点"（内部内容）与"去年获奖统计"（与产品无关、数据口径易被追问）。
2. **修掉页码错乱**：全篇统一「右上 `04 / 21` + 页脚赛事名」，21 页连号无跳号。
3. **建立版式系统**：12 栏网格、五档字号（46 / 30 / 24 / 17 / 15，另有 64 / 96 / 120 三档展示级）、层级间距 = 段间距 2.5 倍；相邻页不重复同一版式。
4. **把"算得清"变成看得见的两页**：P05 用一张三类做法对照（计算器 / 记步换积分 / 企业碳报表各自缺什么）把差异点讲清楚；P23 把十四条因子逐条列出数值 / 单位 / 出处代码（A CPCD、B 生态环境部、C DEFRA、D 中科院×FAO）。
5. **讲稿按 7 分钟重写**：21 段纯口语，配时合计 5 分 43 秒，留 77 秒缓冲；每段只讲一句判断 + 一个证据，细节留给问答。
6. **加了克制的动态**：逐对象入场（after previous，0.35 s 错峰，0.6 s 时长），页面切换 fade 0.4 s；不抢讲解，只帮视线落点。
7. **可编辑**：全部为原生 PowerPoint 文本 / 形状 / 图片（7 张真机截图 + 6 张处理后背景），不是整页图片；字体只用宋体 / 楷体 / Times New Roman，Windows PowerPoint 直接可用。
8. **六张背景图 + 一枚二维码**：封面墨块、收尾横带、四个章节页各一张题头照（上沿出血、下缘化入墨色）；封面右侧印了供评委扫码的二维码，出处与许可见 `素材出处.md`。

## 四、现场怎么用

- **放映**：16:9，F5；动画已设"上一动画之后"，讲完一句自动出下一组，不用一直点。
- **备用**：`交付物/` 里同时放一份 PDF；换机播放前确认已装宋体（Windows 自带），楷体缺失不影响阅读。
- **改字**：全部文本框可编辑；改数字时注意 P05、P23 的数据注脚要一起改。
- **改配色**：全篇只有 8 个色值（见上表），在"设计 → 变体 → 颜色"里改一次即可统一。
- **导出 PDF**：文件 → 导出 → 创建 PDF，勾选"发布后查看"；动画会丢，属正常。
