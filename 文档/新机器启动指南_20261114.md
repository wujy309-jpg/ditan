# 新机器启动指南（给队友 / 换电脑用）

> 目标：在一台**全新的 Mac** 上，从克隆仓库到看见应用跑在模拟器里、手机也能扫码操作。
> 实测环境：macOS + DevEco Studio 26.0.0 + HarmonyOS SDK 5.0.0(12)

---

## 0. 环境要求

| 组件 | 版本 | 检查命令 |
| --- | --- | --- |
| macOS | 14+（本项目在 Apple Silicon 实测） | `sw_vers` |
| DevEco Studio | 26.0.0（**必须装**，提供 hvigor / hdc / 模拟器） | `ls /Applications/DevEco-Studio.app` |
| HarmonyOS SDK | 5.0.0(12)，随 DevEco 安装 | 工程里 `compatibleSdkVersion` 已声明 |
| Node.js | 22+（远程工具用） | `node -v` |
| Google Chrome | 任意近版（**电脑摄像头**功能用，可跳过） | `ls "/Applications/Google Chrome.app"` |
| ffmpeg | 可选（备用抓帧） | `ffmpeg -version` |

---

## 1. 克隆

```bash
git clone <这个仓库地址> ditan
cd ditan
```

> ⚠️ **路径不能含中文** —— hvigor 会硬性拒绝。
> 所以不要把仓库放在 `~/Desktop/河南省应用创新大赛` 这类路径下。
> 推荐 `~/code/ditan`。工作区里的 `project/carbon-footprint` 是**源码正本**，
> 构建脚本会自动同步到一个纯英文临时目录再编译。

---

## 2. 装依赖

```bash
cd project/carbon-footprint
ohpm install          # 只有一个依赖：@ohos/mpchart
```

`ohpm` 在 `DevEco-Studio.app/Contents/tools/ohpm/bin/ohpm`。
同样要求**当前路径不含中文**。

---

## 3. 构建（不需要设备）

```bash
cd ../..            # 回到仓库根
tools/preview.sh build
```

它会做三件事：同步源码到 `/tmp/carbon-footprint` → hvigor 构建 → 用 SDK 自带调试签名材料本地签名。
**全程不需要登录华为账号。** 产物：`/tmp/carbon-footprint/entry/build/default/outputs/default/entry-default-signed.hap`

---

## 4. 跑模拟器

```bash
tools/emulator.sh images      # 看镜像是否已下载
tools/emulator.sh start       # 启动实例（后台）
tools/emulator.sh wait        # 等设备上线
```

> **如果 `start` 报权限错误**（常见于受限环境）：模拟器要写
> `~/Library/Caches/Huawei/Emulator26.0/` 和 `~/.Huawei/Emulator/deployed/`。
> 把它重定向到可写目录即可：
> ```bash
> cp -R ~/.Huawei/Emulator/deployed/carbon /tmp/carbon-emu-home/.Huawei/Emulator/deployed/carbon
> HOME=/tmp/carbon-emu-home /Applications/DevEco-Studio.app/Contents/tools/emulator/Emulator -license accept
> HOME=/tmp/carbon-emu-home /Applications/DevEco-Studio.app/Contents/tools/emulator/Emulator -start carbon
> ```
> 首次还要 `sed -i '' "s|^emuPath:.*|emuPath:/tmp/carbon-emu-home/.Huawei/Emulator/deployed|" \
>   /tmp/carbon-emu-home/Library/Caches/Huawei/Emulator26.0/.emu_config`

## 5. 装上去看效果

```bash
tools/preview.sh all           # 构建 → 安装 → 五页签逐页截图
```

截图落在 `素材/截图/预览/`。看到「碳迹 · 减排账」的账本首屏就成功了。

## 6. 手机远程（可选）

```bash
node tools/remote/server.mjs             # 起桥接服务，会打印带令牌的地址
tools/remote/url.sh                      # 随时取当前可用地址（IP 会变）
```

手机与 Mac 连同一个 Wi-Fi，浏览器打开打印出的地址即可。
详见 [`tools/remote/README.md`](tools/remote/README.md)。

---

## 7. 电脑摄像头（可选）

模拟器里没有相机应用，应用里的「电脑拍照」会向桥接服务要一帧。

第一次点「电脑拍照」时，会自动用 `open -na "Google Chrome"` 拉起一个取景窗口 ——
**这个窗口要留着**，它就是取景器。原理见 `tools/remote/README.md`
（宿主进程没有 camera entitlement，必须借 Chrome 的身份才能拿到系统相机权限）。

## 8. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| `hvigor` 报路径错误 | 工程路径或当前目录含中文，换纯英文路径 |
| `ohpm install` 失败 | 同上；或网络（首次需拉 `@ohos/mpchart`） |
| `preview.sh` 说没有设备 | 先 `tools/emulator.sh start && tools/emulator.sh wait` |
| 模拟器启动报 `Failed to open config file` | 见第 4 节的 `HOME` 重定向 |
| 应用装上了但白屏 | 看日志：`tools/emulator.sh log` |
| 电脑摄像头打不开 | 保持 Chrome 取景窗口打开；它会被自动拉起 |
| 手机打不开远程页面 | IP 变了，跑 `tools/remote/url.sh` 取最新地址 |
