## 1. 蚂蚁森林（支付宝内）—— 最重要的对标对象

**配色**：绿色系，**具体 hex 未查到**。【未查证·印象】

**视觉母题**：**「绿色星球」+ 能量球 + 一棵主树**。
- 【摘要级】2018 年宣布「**绿色星球计划**」，官方表述为"由科技驱动的、人人可以参与的绿色公益平台"（[OFweek](https://ecep.ofweek.com/2...)）
- 【摘要级】数英网 2020 世界环境日项目：**"设计 C4D 星球 & 动物建模，淡彩手绘材质贴图，360° 3D 绿色星球"**，另有"绿色能量榜单""绿色能量星球"。**这是本次最直接的设计手法证据。**

**关键界面与丰富感手法**（【摘要级】，微信文章《打动人心的真实——蚂蚁森林设计升级》）：
> "设计团队定下了三个关键目标：「**真实**」：建立更多真实世界的映射，让用户更有沉浸感；「**细节**」：融入更多故事和彩蛋，让场景活起来，传递'天更蓝，心更暖'的体验；「**高效**」：让用户体验更轻松。"

> "把改版的视觉风格定位在了「**微质感**」上……通过**减少大面积几何色块，并合理增加阴影、高光反射面**，可以有效塑造层次感和真实感。"

**这一条极重要**：升级方向**不是加更多颜色，而是加质感与层次**。

**游戏化**：【摘要级】"种树升级为**生态保护**，成就升级为**我的成就**"，左上角直接显示**证书数量**（[yigujin.cn](https://www.yigujin.cn/5...)）；**背景装扮系统**开放"梭梭树、柠条、沙棘、沙柳、花棒"等主题皮肤。【未查证·印象】能量球收取、合种树、证书墙。

**可抄**：**「一个核心意象 + 微质感」**——选定**一个**贯穿全 App 的意象，统一用**阴影+高光**塑造层次，而非堆砌渐变与大色块。

## 2. 地方碳普惠平台

### 2.1 深圳「低碳星球」
**【摘要级】** 2021-12-17 由深圳市生态环境局**联合腾讯**发布，深圳碳普惠**首个授权运营平台**，核算个人公交地铁减排量累计碳积分；积分可兑「**公益金**」参与守护深圳湿地（[eco.gov.cn](https://www.eco.gov.cn/n...)、36氪、搜狐）。
**可抄**：**"积分转公益金"是很好的情感闭环**，比单纯换优惠券高级。

### 2.2 成都「碳惠天府」
**【摘要级】** 覆盖步行、骑行、公交；积分兑换商城；并支持**线下场景扫码打卡**获积分（如成都图书馆低碳阅读计划）（[人民网](http://kpzg.people.com.cn/n...)、网易）。
**可抄**：**线下场景扫码打卡**，低成本增加真实感。

### 2.3 北京「绿色生活季」
**【摘要级】** 2022-08-10 上线，北京市发改委指导、**绿普惠等承办**；即「**北京个人碳账本**」。分**绿享生活、绿碳积分、绿畅出行等八个板块**（[光明网](https://difang.gmw.cn/b...)、[每经网](http://www.nbd.com.cn/a...)、知乎）。
**可抄**：**「绿 X」前缀板块命名法**——统一命名前缀把功能列表做成品牌语言，成本极低。

### 2.4 浙江「碳普惠」
**【摘要级】** 入口在浙里办 APP / 支付宝 / 微信小程序；提供「**低碳助手**」；宣传语"**开始你的碳普惠虚拟经营人生吧**"，并推出**小游戏**拿红包积分门票（[景宁县政府](http://www.jingning.gov.cn/a...)、宁波北仑区/镇海区政府）。
**可抄**：**"虚拟经营人生"式养成**——官方平台也认可"养成 >> 单纯记账"。

### 2.5 上海碳普惠 /「沪碳行」—— 唯一拿到真实截图的地方平台

**⭐【截图实测】** 独立 App「沪碳行」（[App Store](https://apps.apple.com/cn/app/id1663648846)）：
- **配色**：**深蓝英雄卡 ≈`#2E4E8F`** + 白卡 + 浅灰底（≈`#F2F2F5`）。与绿色主流形成反差（金融服务属性）。
- **关键界面**：深蓝卡内**大数字**"可消费碳积分 **433,784** 个"（超大白字 + 单位后缀）；下一行三列迷你统计"加入沪碳行 **405天** / 累计碳减排量 **560kg** / 累计碳积分 **59元**"；橙红药丸按钮"可兑换数字人民币24.78元"；卡下为"出行福利"两小卡 + "热门活动"两图卡。
- **TabBar**：4 页签，**中间绿色圆形凸起 FAB**。
- **游戏化**：【官方文案】明确有"**践行者排行榜**"——地方平台里少见。

**可抄**：**「英雄区大数字 + 单位后缀 + 三列迷你统计」**是碳类 App 通用骨架，做在深色卡上对比强烈，**直接可抄**。

### 2.6 广东碳普惠 / 横琴「琴碳星人」
**【摘要级】** 广东省碳普惠创新发展中心运营，在广州、东莞、中山、佛山顺德、珠海横琴等地试点；横琴平台名"**琴碳星人**"，并**创新引入家庭账号**（网易，2024-10-17）。
**可抄**：**「家庭账号」**——差异化好点子。

## 3. 银行系个人碳账户

四家银行均取得 App Store 描述与截图，**但截图展示的都是银行 App 首页，未展示碳账户子页面**，故以【摘要级】为主。

**3.1 中信「中信碳账户」**【摘要级】依托信用卡「动卡空间」App；2023 年焕新，**首上线「绿色商城」，呈现全新交互界面**；话术为「**绿色生活名片**」；强调"实时核算、可查询每一笔碳值来源"（[新浪财经](https://finance.sina.com.cn/j...)、[tanpaifang.com](http://www.tanpaifang.com/t...)）。
**可抄**：**"每一笔碳值来源可查"**——把碳做成有**流水明细**的账户，是"账户感"的关键。

**3.2 平安「低碳家园」**【摘要级】面向信用卡+借记卡**全卡客户**，"银行业首个全卡碳账户"；**15 项绿色行为**，享**碳减排量 + 绿色能量的双重价值体系**（知乎，2022-05-18）。
**可抄**：**双货币体系**——「减排量（严肃可核算）」+「能量（轻量可玩）」并行，兼顾可信度与趣味性。**非常适合碳迹。**

**3.3 招行「碳寻星空」—— 母题差异化最佳案例**
**【摘要级】** 招行手机银行低碳平台「**碳寻星空**」，与其他银行"以碳能量或碳减排量计"不同，**以「星光」作为积分奖励**（[零壹财经](https://www.01caijing.com/a...)、[移动支付网](https://www.mpaypass.com.cn/n...)，2023-07）。
**可抄**：**换一套积分隐喻**。所有碳 App 都在用"绿色能量"时，用"星光"立刻区分开。碳迹可用"年轮""碳迹点"。

**3.4 建行「碳账本」**【摘要级】入口：建行 App →「其他金融服务」→「碳账本」；围绕**金融类+生活类两大板块**，覆盖转账汇款、线上支付、低碳出行等 **23 项**行为；另有「**员工碳足迹**」交互专区（[中金在线](http://mp.cnfol.com)、[电子银行网](https://www.cebnet.com.cn/2...)）。
**可抄**：**"账本"隐喻 + 分类板块**。账本视觉天然是**列表+明细+月度汇总**，比"看板"更贴近记账心智，与"碳迹"的"迹"气质一致。

## 4. 地图 / 出行系

**⚠️【截图实测】重要观察**：高德、百度地图、哈啰、滴滴的 App Store 截图**全部展示导航/营销内容，无一张展示碳减排模块**。碳模块在这些超级 App 里属**深层功能**——**碳迹把碳做成首页英雄区，本身就是差异化优势**。

**4.1 高德「绿色出行-碳普惠」**【摘要级】注册获取**个人碳能量账户**，公交/骑行/步行导航获**碳减排能量**可兑权益；与北京市交通委、阿里公益联合上线「**北京 MaaS 绿色出行碳普惠**」；2021-09 将用户碳减排量向北京市政路桥建材集团**售出**，完成碳交易闭环（[北京市交通委](http://jtw.beijing.gov.cn/x...)、新华网）。
**可抄**：**「碳能量账户」+ 交易闭环叙事**——"你的减排量真的被卖出去用于碳中和了"比给积分更有意义感。

**4.2 百度地图「绿动计划」**【摘要级】2020 年上线，**在地图中直观展示碳减排量**；出发前输入起终点选公交/步行/骑行，**每条路线即预估碳减排量**；可用减排量兑礼品（[中国网](http://tech.china.com.cn/i...)）。
**可抄**：**"选择前就显示碳减排量"**——把碳数据前置到决策环节。碳迹"记一笔"可在选出行方式时**实时预告减排量**。

**4.3 哈啰「小蓝C」**【摘要级】骑行里程转换为碳积分「**小蓝C**」；推出行业首张**个人碳减排证书**（知乎，2022-06-15）。
**可抄**：**给积分起专属小名** + **发"碳减排证书"**。证书是极强分享素材，成本极低。

**4.4 滴滴青桔**【摘要级】路径：滴滴 App「青桔骑行」→「碳普惠服务」→「减排量兑换碳积分」→ 碳积分商城；骑行**无感积累**（网易，2024-10/11）。
**可抄**：**"无感积累"**——不要求手动打卡，自动同步即得积分，是留存关键。

## 5. 环保数据类

### 5.1 蔚蓝地图（IPE）—— 唯一完整截图实测的数据类 App

**⭐【截图实测】** 首页（v7.5.4）：
- **配色**：**深蓝灰渐变底**（≈`#2C3542`→`#3D4A5C`），白色大数字，**红徽章 ≈`#E8443A`（"中度"）**、**黄绿徽章 ≈`#B8D94E`（"良"）**作 AQI 语义色，卡片为半透明略亮深色块。
- **视觉母题**：**拟人化卡通 IP「小蓝」**（双马尾、戴口罩、粉色毛衣女孩），配**对话气泡卡**"下午好，小蓝邀你一起拍，点亮小区垃圾分类"+ 垃圾桶插画。
- **关键界面**：顶部城市+天气；**超大数字"16°"与"197"**（AQI），旁列三列小字指标；一条快捷入口条；两日预报卡；深色 4 页签 TabBar。
- **【官方文案】** "48小时分钟级地图""多维度查询地图（含**区域碳排放**、生态物种分布、全球光伏）"，有「微举报」「指尖环保」「**碳易查**」，已接入 AI 大模型（[ipe.org.cn](http://www.ipe.org.cn/i...)）。

**可抄**：**「深色底 + 大数字 + 语义色徽章 + 卡通向导」**——深色让数据"发光"，卡通 IP 把冷数据变暖。非常适合碳迹的**数据看板页**。

## 6. 可借鉴的记账 / 打卡类（**对碳迹性价比最高的一组**）

### 6.1 Forest 专注森林 —— 「一棵树」母题的教科书
**⭐【截图实测】** **深墨绿渐变底**（调色板 `≈#489078`/`≈#30A890`，深色 `≈#003018`，点缀黄绿 `≈#D8D890`）；中央**装树的圆形花盆插画**（棕土 + 淡蓝白花树 + 黄绿圆盆）；上方白字"开始专注种树吧！"；**正中超大白色计时数字"25:00"**；顶栏🍅计时、🔥连续天数、金币。
**【官方文案】** "一棵树苗便会慢慢长大；如果忍不住刷手机，树就会枯萎""**游戏化专注计时器**""达成**里程碑**解锁**新树种与环境音**""解锁**成就**""和全球用户**竞赛**""已在地球种下超 200 万棵真树"。
**可抄**：**一个意象贯穿到底 + 超大数字英雄区 + 意象会"死"**（枯萎机制带来损失厌恶）。碳迹的"碳迹树"可照此：**记录越多越茂盛，断更则枯萎**。

### 6.2 小日常 —— 极简卡片 + 连续打卡
**⭐【截图实测】** 白底、**黑色粗体标题**，灰色副标；主体是**圆形进度环**（橙/绿/蓝三色，环内小插画）+ **彩色圆角方块 Tile 网格**（政治=米棕、考研=粉红、英语=蓝），每格显示时长与"**连续1天🔥**"。
**【官方文案】** "极简体验：零社交、零广告""点击**翻牌**即完成，当下即被奖励「Click！」声""**卡片式 UI**，完美融入暗黑/浅色模式""「**成就卡片**」当日习惯全部完成即可解锁卡片""「统计与趋势」连续打卡天数、完成率、**日历热力图**"。
**可抄**：**「连续 N 天🔥 + 日历热力图 + 成就卡片」三件套**，是打卡类留存核心视觉钩子，实现成本很低。

### 6.3 薄荷健康 —— 三色营养素分区
**⭐【截图实测】** 营销外框橙色渐变（≈`#F5A623`）；数据卡白底：食品名 + "🔥287千卡"大数字，下方**三列营养素**"38克 碳水化合物（绿）/ 16克 蛋白质（红）/ 7克 脂肪（黄）"各配小图标；再下是明细表；底部**绿色药丸按钮"确认记录"**。
**可抄**：**「大数字 + 单位后缀 + 三色分类小图标」**，可直接迁移为碳迹的"减排构成"（出行/饮食/用电三色分区）。

### 6.4 Keep
**⭐【截图实测】** **深紫渐变**（≈`#3A1E6E`→`#6B3FA0`）+ 白色/淡紫大标题，配**金色桂冠徽章**："4.9评分""400,000,000+ Keepers的运动选择""App Store 精选应用"。
**可抄**：**金色桂冠 + 数字徽章组**是"权威感"的廉价来源。碳迹成就页可放"累计减碳 XX kg""相当于种下 X 棵树"这类**桂冠式数字徽章**。

### 6.5 蚂蚁庄园 与 网易云音乐年度报告
- **蚂蚁庄园**【摘要级】：每天答题获肥料、为庄园植物浇水，积累经验值**升级庄园、解锁新功能**；另有「**星星球**」玩法。
- **网易云年度报告**【摘要级】：2022 年度听歌报告有专门 UI 拆解文章；站酷有设计师的年度报告 H5 再设计稿。
- **可抄**：**年度报告式总结页**——碳迹做一页"我的 2025 碳迹年报"，大数字串 + 卡片翻页 + 分享卡收尾。**竞赛演示最出彩、工期最短**的一页。

## 8. 横向规律总结

1. **都把累计减排量做成"英雄区"**，放首屏最上方最大一块——沪碳行、蔚蓝地图、Forest【截图实测】

## 9. 学生竞赛作品的视觉加分点（按性价比排序）

**① 选定一个核心意象并贯穿全 App（最高优先级）**
Forest 靠"一棵树"撑起整个产品。与其做十个页面十种风格，不如让**同一意象**（碳迹树/年轮/星球）出现在首页、记录页、成就页、桌面卡片。
*参考：Forest【截图实测】、蚂蚁森林「绿色星球」【摘要级】*

**② 英雄区：深色卡 + 超大数字 + 单位后缀 + 三列迷你统计**
**投入产出比最高**的一屏。沪碳行的深蓝英雄卡（`433,784 个` + `405天/560kg/59元`）就是标准答案，ArkTS 用 `Column`+`Text` 改字号即可，**不需要任何美术资源**。**【截图实测】**

**③ 「微质感」卡片：阴影 + 高光，而不是更多颜色**
蚂蚁森林官方设计升级的核心结论是"**减少大面积几何色块，增加阴影、高光反射面**"。鸿蒙里就是卡片 `.shadow()` + 一层 `linearGradient` 白色高光叠加 + 圆角。**零成本，但立刻从"学生作业"变成"产品"。****【摘要级·原文引用】**

**④ 连续打卡 🔥 + 日历热力图 + 成就卡片三件套**
小日常用这三样撑起整个留存体系。鸿蒙的 `Grid` + 纯 `Column` 拼色块就能画热力图，成就卡片只需圆角卡 + 分享按钮。**【截图实测+官方文案】**

**⑤ 一页「年度碳迹报告」分享卡**
网易云年度报告本质只是**大数字卡片的分页串烧**。碳迹做一页"我的一年碳迹"——总减碳量、相当于种了几棵树、最长连续天数、最常做的低碳行为——配统一渐变底 + App 名称水印，**答辩现场最易拿分**。**【摘要级：网易云年度报告；手法为通用结论】**

> **避免踩坑**：不要为"丰富"而堆 3D 和大渐变。上述截图实测的成熟产品**首屏元素都很克制**（1 个英雄区 + 2–3 个功能卡 + TabBar）。华为官方设计规范亦要求"主色相不超过 3 种""核心颜色 1–2 个且占比最大"。**加分点在层次与质感，不在元素数量。**
